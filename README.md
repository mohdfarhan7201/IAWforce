# Force Motors Website (Pure HTML, CSS & JavaScript)

This project has been converted into a **100% Pure HTML, CSS, and Vanilla JavaScript** static website. No React, Node server, or TypeScript build step is required.

## 📁 Project Structure

- `index.html` — Main Home Page
- `about.html` — About Force / Company Page
- `local_assets/` — Local CSS stylesheets, JavaScript files, images, icons, and SVG assets
- `favicon.svg` & `icons.svg` — Website icons

## 🚀 How to Run

1. **Direct File Browser**: You can directly double-click `index.html` or open `index.html` in any browser (Chrome, Edge, Firefox, Safari).
2. **Local HTTP Server** (Optional):
   - Using VS Code Live Server extension: Right click `index.html` -> "Open with Live Server"
   - Using Python: `python -m http.server`
   - Using Node / npx: `npx serve`
